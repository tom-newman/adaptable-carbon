## Overview

In this project I have used the IBM Carbon Design System as a base, to build out a theming system, allowing me to generate a large set of fully compliant web components, using latest native browser technologies.

Below you can see examples of how these can be tuned to fit almost any brand - serioues, trendy, finincial, social etc. can all be acheived as I have tied the relevant styling parameters and metrics to a single object, so this can be easily configured to fit the purpose.
